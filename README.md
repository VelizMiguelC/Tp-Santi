# Tp-Santi

Trabajo práctico de Taller Web: página de un supermercado online (e-commerce) llamada **La Canasta**.

Hecha solamente con HTML y CSS.

## Páginas

- `index.html` - Inicio, con botones a las categorías y la sección de ofertas
- `almacen.html` - Almacén
- `bebidas.html` - Bebidas
- `lacteos.html` - Lácteos
- `carnes.html` - Carnes
- `frutas-verduras.html` - Frutas y Verduras
- `limpieza.html` - Limpieza

Los estilos están en `css/estilos.css`.

## Cómo verla

Abrir el archivo `index.html` con cualquier navegador.
